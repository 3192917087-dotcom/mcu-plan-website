# 单片机论文工作台 V2

这是与 `studio-next` 并行的新版本。旧版不会被覆盖。

## 核心流程

1. 项目库：多个项目独立保存、切换、复制和导入导出。
2. 方案设计：题目必填，附加要求可选，输出一份题目、器件与功能方案。
3. 论文写作：资料录入、引脚确认、自动规划结构、分章生成、技术复核、DOCX 下载；目录、图表、公式及中英文题目等内容统一在论文生成阶段完成。
4. 每章完成立即保存；生成中、暂停、失败或质量检查未通过时均可下载当前稿。

## 本地访问

由仓库根目录的静态服务器提供服务后访问：

`http://127.0.0.1:8765/studio-v2/`

API 默认配置继续读取 `studio-next/github-config.js`，用户也可以在 V2 设置中替换为其他 OpenAI 兼容接口。
